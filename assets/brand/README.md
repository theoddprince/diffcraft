# DiffCraft brand assets

The DiffCraft logo mark (the split "D") and the wordmark, supplied by the project owner.

| File | Use |
|---|---|
| `diffcraft-icon-{32,64,128,256,512,1024}.png` | App icon, transparent corners (window icon, Linux, macOS) |
| `diffcraft.ico` | Windows executable icon (16–256 px) |
| `diffcraft-wordmark-on-light*.png` | Wordmark for light backgrounds, transparent |
| `diffcraft-wordmark-on-dark*.png` | Wordmark for dark backgrounds, transparent |
| `diffcraft-banner-{light,dark}.png` | Wordmark banners with background (README) |

The transparent and resized variants are generated from the originals. Use the logo only to refer
to DiffCraft. Don't alter it to suggest a different product.
